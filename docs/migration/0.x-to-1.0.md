# 0.x → 1.0.0 마이그레이션 가이드

이 문서는 `Jakarta_To_Javax_Servlet_Adapter` 0.0.1 사용자가 1.0.0 으로 업그레이드할 때 필요한 변경 사항을 안내합니다.

요구사항 추적: **MIG-REL-001**

---

## 1. 핵심 요약

| 항목 | 0.x | 1.0.0 |
|---|---|---|
| 그룹 좌표 | (단일 jar) | 멀티모듈 + BOM |
| 주 패키지 | `adapter.jakarta.servlet.*` / `adapter.javax.servlet.*` / `adapter.servletElementConverter.*` | `adapter.jakarta.servlet5.*` / `adapter.javax.servlet5.*` / `adapter.servletElementConverter5.*` |
| Servlet 5 (Jakarta 5.0) 지원 | ✓ | ✓ (`servlet5` 모듈) |
| Servlet 6 (Jakarta 6.0) 지원 | ✗ | ✓ (`servlet6` 모듈) |
| Servlet 6.1 (Jakarta 6.1) 지원 | ✗ | ✓ (`servlet61` 모듈) |
| Maven Central 게시 | ✗ | ✓ |
| 0.x 패키지 alias | n/a | **유지 (`@Deprecated`, v2.0 제거 예정)** |

요점: **소스 import 변경 없이도 1.0.0 의존만 교체하면 컴파일 됩니다.** 단, 0.x 패키지는 `@Deprecated(forRemoval = true, since = "1.0.0")` 로 표시되며 **v2.0 에서 제거 예정**입니다. 가능한 한 빨리 신규 패키지로 마이그레이션하세요.

---

## 2. 의존 좌표 변경

### 2.1 0.x (예시)

```gradle
// build.gradle (Groovy DSL)
dependencies {
    implementation 'com.snoworca:Jakarta_To_Javax_Servlet_Adapter:0.0.1'
}
```

### 2.2 1.0.0 (BOM 사용 권장)

```gradle
dependencies {
    implementation platform('com.snoworca:jakarta-to-javax-servlet-adapter-bom:1.0.0')

    // 사용하는 Servlet 버전에 맞는 모듈 선택
    implementation 'com.snoworca:jakarta-to-javax-servlet-adapter-servlet5'   // Jakarta Servlet 5.0
    // implementation 'com.snoworca:jakarta-to-javax-servlet-adapter-servlet6'   // Jakarta Servlet 6.0
    // implementation 'com.snoworca:jakarta-to-javax-servlet-adapter-servlet61'  // Jakarta Servlet 6.1
}
```

> 0.x 와 동등한 동작은 `servlet5` 모듈입니다. 기존 환경(Tomcat 10.0, Jetty 11) 그대로 사용하면 됩니다.

### 3.2 사용자 진입점 (변경 없음)

`com.snoworca.ServletAdapter` 의 정적 메서드 (예: `ServletAdapter.adaptToJavax(...)`) 는 1.0.0 에서도 유지됩니다. 대다수 사용자는 이 진입점만 사용하므로 추가 작업이 없습니다.

## 4. alias 사용 예시 (단기 호환)

```java
// 0.x 코드 — 1.0.0 에서도 그대로 컴파일됩니다 (단 deprecation 경고).
import adapter.jakarta.servlet.http.HttpServletRequest;   // @Deprecated alias
import adapter.servletElementConverter.ServletConverter;  // @Deprecated alias

public class MyAdapter {
    public jakarta.servlet.http.HttpServletRequest wrap(javax.servlet.http.HttpServletRequest req) {
        return new HttpServletRequest(req);  // 정상 동작
    }
}
```

권장 마이그레이션:

```java
import adapter.jakarta.servlet5.http.HttpServletRequest;       // 신규 경로
import adapter.servletElementConverter5.ServletConverter;       // 신규 경로

public class MyAdapter {
    public jakarta.servlet.http.HttpServletRequest wrap(javax.servlet.http.HttpServletRequest req) {
        return new HttpServletRequest(req);
    }
}
```

## 5. v2.0 제거 일정

* **1.0.0** — alias 도입 + `@Deprecated(forRemoval = true)` 표시.
* **1.x 패치 라인** — alias 유지. 신규 import 권장.
* **v2.0 (시기 미정)** — 0.x alias **전부 제거**. 사용자는 반드시 신규 패키지로 마이그레이션해야 합니다.

CHANGELOG / GitHub Releases 에서 v2.0 발표 시 추가 안내가 게시됩니다.

---

## 6. 변경 사항 요약 (정보 손실 / 비호환 경고)

세부 호환성 매트릭스는 `README.md` 의 호환성 표 + `docs/spec/` 의 정보 손실 5개 항목 (FR-CONV-013 ~ FR-CONV-017) 을 참조하세요.

* `getRealPath(String)` — Servlet 5.0+ 에서 `ServletRequest` 인터페이스에서 제거. 폴백 동작은 그대로 유지.
* `Cookie` attribute API — javax 4.x 에 부재. 폴백 정책 D (no-op + WARN-once) 적용.
* 그 외 세부 정책은 `docs/spec/` 참조.
