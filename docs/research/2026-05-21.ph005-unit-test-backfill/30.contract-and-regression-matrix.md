### §4.2 회귀 trap 핵심 영역

#### Trap 1 — common 모듈 testFixtures 변경

- **trap**: `common/src/testFixtures/java/com/snoworca/contract/DelegationContractTest.java` (driver) 변경 시 servlet5/6/61 의 ContractTest 39건 모두 동시 영향
- **시나리오**: backfill 중 reflection 알고리즘에 새 blacklist case 가 필요해서 driver 시그니처 변경
- **mitigation**: PH-005 task 목록에 common 변경 항목 없음. driver 변경 발생 시 즉시 회귀 (Contract 39 PASS → 일부 FAIL).
- **권장**: T-PH005-08 review 시 `git diff common/src/testFixtures/` 0 line 변경 확인.

#### Trap 2 — common/main 의 ConverterSupport / AdapterUnwrap 변경

- **trap**: `common/src/main/java/adapter/common/{AdapterUnwrap,ConverterSupport,HttpComponentConverter,EnumsConverter,ReadListenerConverter,WriteListenerConverter}.java` 변경 시 3 모듈 unit/contract/IT/BM 모두 영향
- **시나리오**: backfill 도중 공유 helper 의 helper method signature 변경 필요
- **mitigation**: PH-005 단위 backfill 은 *기존 어댑터 동작 검증*이 목적 — common 변경 동반 불필요. 동반 시 PH-003 결함 fix scope 로 분리해야 함.

#### Trap 3 — 어댑터 클래스 자체 변경

- **trap**: backfill 도중 어댑터 클래스가 mock 검증 실패 시, 어댑터 코드를 수정하면 BM / Contract / IT 회귀 발생
- **시나리오**: 신규 단위 테스트가 기존 어댑터 버그를 발견 → 어댑터 수정 → 다른 시나리오 회귀
- **mitigation**: PH-005 plan 의 task type 은 "code (test green phase)" 이며 *production code 변경 금지*. 어댑터 버그 발견 시 PH-003 결함 fix task 로 escalate.
- **rollback**: 각 task 의 `rollback: "신규 추가 테스트 파일 삭제"` — production code 미변경 전제.

#### Trap 4 — `excludeTags 'integration'` 의도 의도와 신규 테스트 태그 누락

- **trap**: T-PH005-01~07 신규 테스트에 실수로 `@Tag("integration")` 부착 또는 누락
- **시나리오**: integration tag 부착 시 `gradlew test` 카운트 미반영 → DoD ≥71/76/115 미달.
- **mitigation**: 신규 backfill 테스트는 unit pure mockito 기반 — `@Tag` 미부착이 정답. PR 리뷰 시 `git grep "@Tag(\"integration\")" servlet[56]*/src/test/java/com/snoworca/adapter/{jakarta,javaxside,converter}` 0 hit 확인.

#### Trap 5 — Mockito 설정 변경 / RETURNS_SMART_NULLS

- **trap**: PH-005 plan 에 명시된 `Mockito RETURNS_SMART_NULLS` 가 기존 mock 객체와 default `RETURNS_DEFAULTS` 충돌
- **시나리오**: 신규 backfill 이 SMART_NULLS 채택, 기존 어댑터 unit/defect 가 default 가정 → 회귀
- **mitigation**: 신규 테스트 클래스 내부에서만 SMART_NULLS strategy 사용 (별도 mock factory 미공유).

#### Trap 6 — JaCoCo finalizedBy 'jacocoTestReport' 부작용

- **trap**: `tasks.withType(Test).configureEach { finalizedBy 'jacocoTestReport' }` 가 `gradlew test` 후 자동 report 생성. test FAIL 무관하게 report 생성 — DoD 정합성 영향 없음.
