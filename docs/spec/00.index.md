## 1. Purpose

본 SRS 는 `Jakarta_To_Javax_Servlet_Adapter` 1.0 출시의 요구사항을 정의한다. 이 모듈은 `javax.servlet 4.0` 기반 레거시 웹 애플리케이션과 `jakarta.servlet 5.0 / 6.0 / 6.1` 컨테이너 사이의 **양방향 어댑터**다.

1.0 의 핵심 차별점은 다음과 같다.

1. 단일 어댑터에서 **multi-module Gradle 토폴로지**로 재구조화 (`common / servlet5 / servlet6 / servlet61 / bom`).
2. Jakarta Servlet **5.0 / 6.0 / 6.1 동시 지원** (분리된 모듈).
3. 양방향 변환의 **의미론 명세** 및 **폴백 정책** 정립.
4. 0.0.1 코드의 Critical 결함 7건 일괄 수정.
5. Tomcat embed 기반 통합 테스트 슈트 도입.

상세 배경은 [docs/research/00.index.md](../research/00.index.md) 참조. 본 SRS 의 의사결정 SSOT 는 [docs/research/80.decisions.md](../research/80.decisions.md).

## 10.1 Local Conventions

본 SRS 는 SRS-MD Authoring Rules v1.0.0 을 따르되 다음 프로젝트 로컬 규약을 추가한다.

| Convention | 설명 |
|---|---|
| Trace Links 형식 | SRS-MD §23.1 의 표 형식 대신 `- {relation_type}: {ref}` bullet 형식을 허용한다. relation_type 은 `depends_on / supports / verifies / verified_by / supersedes / supersedes_def / enforces / impacted_by / impl_in / relates_to / defers_to / documents / provides` 중 하나를 사용한다. |
| Cross-scope Dependencies | Index §8 은 모든 scope 간 관계의 전수 집합이다. 각 scope SRS §5 의 관계는 모두 Index §8 에 등록된다. 동일 관계는 한 방향만 등록한다 (역방향은 cross-reference 로 인지). Relation 값 정합성: `depends_on / provides / verifies / verified_by / enforces / overlaps / documents / requires` 가 표준. |
| Verification Evidence 빈 행 | 모든 `planned` REQ 의 Verification Evidence 표는 헤더만 두고 행은 비운다. 구현 완료 시 row 를 추가한다. |
| Source 메타데이터 | 가능한 한 Markdown link 로 작성한다 (`[docs/research/80.decisions.md D1.1](../research/80.decisions.md)` 형태). |
